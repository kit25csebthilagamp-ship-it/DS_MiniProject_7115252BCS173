# Ticket Booking System (C Project)

## Project Title

Ticket Booking System using C

##  Description

This project is a simple Ticket Booking System developed in C. It allows users to book tickets, view available tickets, and manage reservations efficiently. The system demonstrates real-world use of data structures and algorithms.

## 6 Features

* 🎫 Book Tickets
* 📋 View All Tickets
* 🔍 Search Tickets (Binary Search)
* 🔄 Sort Tickets (Quick Sort)
* 💻 Menu-driven program

## Technologies Used

* C Programming Language
* Data Structures & Algorithms

## How It Works

* Ticket data is stored using arrays
* Sorting is used to organize tickets
* Searching helps find tickets quickly
* Menu allows user interaction

##  Time Complexity

* Sorting: O(n log n)
* Searching: O(log n)

## How to Run

1. Compile the program:

   ```
   gcc ticket_booking.c -o ticket_booking
   ```
2. Run the program:

   ```
   ./ticket_booking
   ```
